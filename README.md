### NeoVim (LazyVim)
» Diretório: `~/.config/nvim/`
- [options.lua](/nvim/lua/config/options.lua)
- [init.lua](/nvim/init.lua)
```css
|-- nvim/
|   |-- lua/
|   |   |-- config/
|   |   |   |-- autocmds.lua
|   |   |   |-- keymaps.lua /* Mapeamento de teclas */
|   |   |   |-- lazy.lua 
|   |   |   |-- options.lua /* Opções principais do Lazy Vim*/
|   |   |-- plugins/
|   |       |-- exemple.lua
|   |       |-- gruvbox.lua /*exemplo de tema*/
|   |-- init.lua
```
